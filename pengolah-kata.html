APLIKASI PENGOLAH KATA DAN PENGOLAHAN DOKUMEN

Hampir semua pekerjaan di dunia kerja menggunakan dokumen: surat, laporan, daftar menu, brosur paket wisata, formulir tamu, sampai surat penawaran kerja sama. Di bidang Perhotelan, dokumen yang rapi menunjukkan sikap profesional.

Panduan Belajar Interaktif: Setiap perintah ditampilkan dengan ikon berwarna sesuai aslinya di toolbar. Gambar antarmuka memakai nomor kuning (Word di komputer) dan huruf kuning (Google Docs di HP). Gunakan Simulator Langsung di bawah ini untuk mempraktikkan setiap tombol!

Tujuan Pembelajaran

  • 1. Menyebutkan fungsi utama program pengolah kata.
  • 2. Mengidentifikasi contoh aplikasi pengolah kata (Word, Docs, WPS, LibreOffice).
  • 3. Menjelaskan fungsi Ctrl+S, Ctrl+C, dan shortcut lainnya.
  • 4. Mengidentifikasi ikon Bold, Italic, Align Center, & Paragraph Alignment.
  • 5. Menyebutkan perintah mencetak (Print / Ctrl+P) & menyimpan dokumen baru.
  • 6. Membuat laporan destinasi wisata lengkap dengan gambar, tabel, dan sumber.

PENGENALAN

Pengenalan Aplikasi Pengolah Kata

Pengertian & Istilah Penting

Aplikasi pengolah kata (word processor) adalah program komputer atau aplikasi HP yang digunakan untuk membuat, mengetik, mengedit, memformat, menyimpan, dan mencetak dokumen berbasis teks yang dapat dilengkapi gambar, tabel, dan objek lain.

Dokumen

Hasil kerja di aplikasi pengolah kata, misalnya surat atau laporan.

Mengedit

Mengubah isi dokumen (menambah, menghapus, memperbaiki).

Memformat

Mengubah tampilan dokumen (jenis huruf, ukuran, rata paragraf).

Manfaat Utama Pengolah Kata:

Hemat waktu: bisa dipakai ulang sebagai templat.
Hasil rapi & profesional: tulisan seragam.
Mudah diperbaiki: tanpa perlu menulis ulang.
Mudah dibagikan: lewat e-mail atau pesan.
Hemat tempat: ratusan file dalam satu perangkat.
Kolaborasi: disunting bersama (Google Docs).

Enam Fungsi Utama

1
Membuat dokumen: Menulis surat konfirmasi reservasi.
2
Mengedit dokumen: Mengganti tanggal menginap tamu.
3
Memformat dokumen: Membuat daftar menu restoran menarik.
4
Menyisipkan objek: Menempel foto kamar pada brosur.
5
Menyimpan dokumen: Menyimpan Brosur_Wisata.docx.
6
Mencetak dokumen: Mencetak formulir registrasi tamu.

Cara Membuat Dokumen Baru pada Masing-Masing Aplikasi

Langkah Praktik PC & HP
1. Microsoft Word Shortcut: Ctrl + N
  1. Di Komputer: Buka aplikasi Microsoft Word lewat menu Start atau ikon di Desktop.
  2. Klik Blank document (Dokumen kosong) untuk mulai dari halaman putih, atau pilih templat yang tersedia.
  3. Jika Word sudah terbuka, klik tab File → New → Blank document atau tekan Ctrl + N.
  4. Di HP: Buka aplikasi Word → ketuk ikon + (Baru) di pojok kanan atas → pilih Dokumen kosong.
2. Google Docs docs.google.com
  1. Di Komputer (Browser): Masuk ke akun Google, buka docs.google.com (atau Google Drive → klik + Baru → Google Dokumen).
  2. Klik kartu bertanda + (Blank / Kosong) pada bagian Start a new document.
  3. Ketik judul file pada kotak Untitled document di pojok kiri atas agar otomatis tersimpan di Google Drive.
  4. Di HP: Buka aplikasi Google Docs → ketuk tombol + (Tambah) di kanan bawah → pilih Dokumen baru.
3. WPS Writer (WPS Office) PC & Android/iOS
  1. Di Komputer: Buka WPS Office → pilih menu Docs di panel kiri → klik + Blank.
  2. Di HP: Buka aplikasi WPS Office → ketuk tombol + (Buat) berwarna merah di bagian bawah.
  3. Pilih ikon Doc (Dokumen berwarna biru) → ketuk + Kosong (Blank) untuk mulai mengetik.
4. LibreOffice Writer Shortcut: Ctrl + N
  1. Buka aplikasi LibreOffice (atau langsung LibreOffice Writer) dari menu aplikasi komputer.
  2. Pada layar awal Start Center, klik menu Writer Document di panel sebelah kiri.
  3. Jika sudah berada di dalam jendela kerja, klik menu File → New → Text Document atau tekan Ctrl + N.

TOOLBAR & SHORTCUT

Kartu Ikon Toolbar & Shortcut Keyboard

B
Ctrl + B

Bold (Tebal)

Menebalkan huruf agar teks tampak menonjol (judul, subjudul, jam sarapan 06.30–10.00).

I
Ctrl + I

Italic (Miring)

Memiringkan huruf untuk istilah asing (check-in, homestay), judul buku/film, atau nama ilmiah.

Ctrl + E

Align Center (Rata Tengah)

Meratakan teks di tengah halaman (judul & kop surat). Berbeda dengan Justify (Ctrl+J) yang meluruskan tepi kiri dan kanan.

Ctrl + S

Save (Simpan)

Menyimpan dokumen ke penyimpanan agar tidak hilang saat listrik padam. Dokumen baru otomatis membuka kotak Save As.

Ctrl + C / Ctrl + V

Copy & Paste (Salin & Tempel)

Ctrl + C menyalin teks tanpa menghapus aslinya, lalu Ctrl + V untuk menempel. Berbeda dengan Ctrl + X (Cut) yang memotong/memindahkan teks.

Ctrl + P

Print (Cetak)

Mencetak dokumen digital ke kertas melalui printer. Gunakan Print Preview untuk mengecek tampilan agar kertas tidak terbuang.

PENGELOLAAN & EKSPOR

Pengelolaan Dokumen, Objek, Ekspor PDF & Praktik di HP

Kelola Dokumen, Save As, Print & PDF

  • Mengetik & Mengedit Teks: Teks otomatis turun ke baris baru (word wrap). Jangan tekan Spasi berkali-kali untuk menggeser teks! Gunakan Backspace (hapus ke kiri kursor), Delete (hapus ke kanan kursor), Undo (Ctrl+Z), dan Redo (Ctrl+Y).
  • Aturan Nama File yang Baik: Singkat, jelas, pakai garis bawah (_) atau tanda hubung (-), contoh: Laporan_Wisata_Kelas-X-PH1_Ayu.docx. Hindari karakter terlarang \ / : * ? " < > |.
  • Save vs Save As: Save (Ctrl+S) memperbarui file yang sudah bernama tanpa kotak dialog. Save As (F12) menyimpan salinan dengan nama, lokasi, atau format baru (misal ke PDF).
  • Perbedaan DOC, DOCX, dan PDF: DOC (format lama Word 97-2003, ukuran besar), DOCX (format modern Word XML, efisien, masih dapat diedit), PDF (Portable Document Format, tampilan tetap sama di semua perangkat & sulit diedit — cocok untuk dokumen final).

Pemformatan, Objek & Aplikasi di HP

  • Format Halaman & Paragraf: Kertas A4 (21 × 29,7 cm), orientasi Portrait (Landscape untuk tabel lebar), Margin Normal 2,54 cm atau skolastik (Atas 3, Kiri 4, Bawah 3, Kanan 3 cm), indentasi baris pertama 1,25 cm, spasi 1,5, Header/Footer & nomor halaman.
  • Menyisipkan Gambar, Tabel, Simbol & Hyperlink: Seret titik sudut gambar agar proporsional (tidak gepeng); atur posisi In line with text atau Wrap text. Pada tabel gunakan Insert/Delete row/column dan Merge cells. Sisipkan simbol peringkat (★★★★) dan tautan (Ctrl+K) dengan mencantumkan sumber gambar.
  • Google Docs & WPS Office di HP Android: Ketuk + (Buat) → Dokumen baru. Blok teks → ketuk ikon A (Format) → tab Text untuk B / I / U / warna atau tab Paragraph untuk perataan & spasi. Sisipkan gambar/tabel lewat ikon +. Ekspor PDF via ⋮ → Bagikan & ekspor → Simpan sebagai PDF (atau Tools → Export to PDF di WPS). Aktifkan mode Tersedia secara offline agar hemat kuota!

Rangkuman Inti Bab 3

  1. Pengolah kata berfungsi membuat, mengedit, memformat, menyimpan, dan mencetak dokumen teks.
  2. Contoh aplikasi: Microsoft Word, Google Docs, WPS Writer, LibreOffice Writer.
  3. Ctrl+S = simpan; Ctrl+C = salin; Ctrl+V = tempel; Ctrl+X = potong; Ctrl+P = cetak; Ctrl+Z/Y = Undo/Redo.
  4. Bold (B) menebalkan; Italic (I) memiringkan; Underline (U) menggarisbawahi.
  5. Paragraph Alignment mengatur perataan paragraf: kiri, tengah (Align Center), kanan, rata kiri-kanan (Justify).
  6. Menyimpan dokumen baru: Ctrl+S → pilih lokasi → beri nama → pilih format → Save.
  7. Gunakan Print Preview sebelum mencetak; pilih PDF untuk dokumen final.

Glosarium Penting

Clipboard: Tempat penampungan sementara teks hasil Copy/Cut.
Ribbon: Panel deretan perintah di bagian atas Microsoft Word.
Ruler: Penggaris pengatur margin dan indentasi paragraf.
Justify: Perataan teks lurus di tepi kiri dan kanan sekaligus.
Header & Footer: Teks berulang di bagian atas & bawah halaman.
Status Bar: Bilah info jumlah halaman, jumlah kata, & zoom.

6. Jelaskan fungsi kombinasi tombol Ctrl + C dan perbedaannya dengan Ctrl + X!

▶ Lihat Kunci Jawaban & Pedoman Skor (Maks. 10)
Ctrl + C (Copy) menyalin teks tanpa menghapus teks aslinya. Ctrl + X (Cut) memotong teks sehingga teks asli hilang dari tempat asal dan dipindahkan.

7. Jelaskan fungsi menu Paragraph Alignment dan sebutkan empat pilihan perataannya!

▶ Lihat Kunci Jawaban & Pedoman Skor (Maks. 10)
Paragraph Alignment mengatur perataan paragraf terhadap margin. Empat pilihannya: Align Left, Align Center, Align Right, dan Justify.

8. Jelaskan fungsi ikon Italic (I) dan berikan dua contoh penggunaannya dalam dokumen!

▶ Lihat Kunci Jawaban & Pedoman Skor (Maks. 10)
Italic memiringkan huruf. Contoh penggunaan: istilah asing (check-in, homestay) dan judul buku/sumber pustaka.

9. Tuliskan langkah-langkah menyimpan dokumen baru dengan nama "Surat_Reservasi" di komputer atau HP!

▶ Lihat Kunci Jawaban & Pedoman Skor (Maks. 10)
Tekan Ctrl + S (di HP: Save / Ganti nama) → pilih folder lokasi → ketik nama "Surat_Reservasi" → pilih format .docx → klik Save.

10. Jelaskan fungsi ikon Align Center dan berikan satu contoh bagian dokumen yang diratakan tengah!

▶ Lihat Kunci Jawaban & Pedoman Skor (Maks. 10)
Align Center meratakan teks di tengah halaman antara margin kiri dan kanan. Contoh: judul laporan, judul menu restoran, atau kop surat hotel.

Kasus 1 – Surat Konfirmasi Reservasi

Kamu bekerja sebagai resepsionis magang. Buatlah dokumen surat konfirmasi reservasi (nama tamu, tanggal menginap, tipe kamar). Judul dibuat Bold dan Align Center. Simpan dengan nama yang benar sebagai dokumen baru.

▶ Lihat Poin Kunci Penilaian
Gunakan Bold (Ctrl+B) dan Align Center (Ctrl+E) pada judul. Simpan dengan Ctrl+S → pilih lokasi → beri nama Surat_Konfirmasi_Reservasi.docx → Save.

Kasus 2 – Menyalin Alamat Hotel

Sebuah alamat hotel perlu muncul pada tiga surat berbeda. Tunjukkan cara menyalinnya dengan Ctrl + C dan Ctrl + V (atau menu salin di HP). Sebutkan fungsi Ctrl + C.

▶ Lihat Poin Kunci Penilaian
Blok alamat → tekan Ctrl+C (menyalin tanpa menghapus teks asli) → letakkan kursor di surat tujuan → tekan Ctrl+V (menempel).

Kasus 3 – Daftar Menu Sarapan Hotel

Buat daftar menu sarapan hotel: nama menu dalam Italic, harga dalam Bold, judul menu Align Center, dan isi daftar Align Left. Jelaskan fungsi tiap perintah yang dipakai.

▶ Lihat Poin Kunci Penilaian
Italic (I) memiringkan nama menu asing; Bold (B) menebalkan harga agar jelas; Align Center menengahkan judul; Align Left meratakan daftar ke kiri.

Kasus 4 – Mencetak Pengumuman Check-out

Pengumuman jam check-out harus dicetak sebanyak 3 salinan. Tuliskan perintah dan langkah mencetak, termasuk Print Preview. Jika printer tidak tersedia, jelaskan alternatifnya.

▶ Lihat Poin Kunci Penilaian
Tekan Ctrl+P → periksa Print Preview → pilih printer → isi Copies: 3 → klik Print. Alternatif tanpa printer: Export ke PDF lalu cetak di tempat fotokopi.

Kasus 5 – Proyek Laporan Destinasi Wisata

Selesaikan proyek "Laporan Hasil Pencarian Informasi Destinasi Wisata" lengkap dengan judul (Bold, 14 pt, Center), pendahuluan (Justify, spasi 1,5), gambar, tabel ringkasan, dan daftar sumber.

▶ Lihat Poin Kunci Penilaian
Pastikan seluruh komponen lengkap dan simpan dalam dua format: .docx untuk arsip edit dan .pdf untuk dokumen final yang dikirim ke guru.
